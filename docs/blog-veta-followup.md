# 추가 개선 작업 (최대 3개)

기존 검색·읽기·404 개선 이후 추가 작업은 아래 세 가지로 제한합니다.

1. 작성 내용 유실 방지
2. 동시 수정 충돌 감지
3. 같은 카테고리의 다른 글 안내

## 1. 작성 내용 유실 방지

- 입력 직후 다른 페이지로 이동하거나 탭이 숨겨지면 800ms 지연을 기다리지 않고 임시저장을 시도합니다.
- 서버 저장 이후 변경 사항이 있으면 탭 종료 시 브라우저의 기본 경고를 요청합니다. 브라우저 정책상 경고가 항상 표시되는 것은 아닙니다.
- 에디터를 다른 게시글로 이동하면 인스턴스를 새로 만들고, 이전 글의 임시저장은 이전 키에 보관합니다.
- 서버 저장 성공 후 브라우저 저장소 삭제가 실패해도 서버 저장 실패로 표시하지 않습니다.
- 복원할 임시저장의 필드 타입을 검증합니다. 저장소가 차단되거나 용량이 부족하면 서버 저장을 안내합니다.
- 로컬 임시저장은 기존과 같이 같은 브라우저에만 남으며 복원은 명시적인 버튼으로 수행합니다.

## 2. 동시 수정 충돌 감지

- `V4__post_edit_version.sql`은 기존 데이터를 보존하며 `version bigint NOT NULL DEFAULT 0`만 추가합니다.
- 관리자 조회·저장 응답은 `version`을 반환합니다. 편집기는 저장 시 이 값을 함께 보내며, 임시저장에도 편집 기준 버전을 보관합니다.
- 서버는 기존 행 잠금 안에서 기준 버전을 비교합니다. 다르면 HTTP 409 `POST_CONFLICT`를 반환하고 내용을 변경하지 않습니다. 편집 내용과 임시저장은 유지되며 새 탭에서 최신 글을 확인할 수 있습니다.
- 저장·발행·발행 취소·삭제 시 버전을 증가시킵니다. 발행/취소 요청도 선택 쿼리 `version`을 지원하므로 저장과 발행 사이의 변경을 감지할 수 있습니다.
- 기존 Agent 및 API 클라이언트 호환을 위해 `version` 생략은 허용합니다. 따라서 충돌 보호는 버전을 보내는 클라이언트에 적용됩니다. 기존 버전 정보 없는 로컬 임시저장은 현재 조회 버전을 기준으로 복원됩니다.
- 공통 API 오류에서 서버의 임의 메시지를 그대로 노출하지 않고 알려진 충돌 코드만 사용자 안내에 반영합니다.

## 3. 같은 카테고리의 다른 글 안내

- 공개 게시글 상세 응답에 `relatedPosts` 배열을 추가합니다. 본문 하단에서 기존 게시글 카드로 표시합니다.
- 현재 글을 제외하고 같은 카테고리의 최신 공개 글을 최대 3개까지 제공합니다. 발행 시각이 지나지 않은 글, 초안, 삭제 글은 제외합니다.
- 미분류 글이나 다른 공개 글이 없는 카테고리는 빈 배열을 반환하고 안내 영역을 표시하지 않습니다.
- 기존 공개 인덱스를 활용하는 제한된 쿼리이며 추천 글의 Markdown 본문은 가져오지 않습니다. 추가 HTTP 요청이나 새 라이브러리 없이 상세 응답에 포함합니다.

## 최종 검증 및 종료

- 원본 `node_modules` 잠금 문제를 피해, 기존과 같이 무시되는 `artifacts/blog-veta-frontend`에 실제 소스와 동일한 잠금 파일을 복사해 검증했습니다. 최종 `npm ci`, `npm test`(55개), `npm run build` 성공.
- Java 21에서 `gradlew.bat build postgresTest --no-daemon` 성공: 일반 테스트 17개, 실제 PostgreSQL 통합 테스트 19개 통과. 새 버전 마이그레이션과 오래된 수정/발행 거부, 공개 추천 조건을 검증했습니다.
- 실제 백엔드와 Vite 프록시를 연결한 Chromium 검증: 1440px 데스크톱 및 390px 모바일에서 검색·목차·문단 직접 접속·같은 카테고리 글 2개 표시/이동·404 회귀 통과. JavaScript 오류 및 가로 넘침 없음.
- 스크린샷과 JSON 결과: `artifacts/blog-ui/1794930262859/`. `node scripts/verify-reader-ui.mjs`로 재현할 수 있습니다(기본 Vite 15173, 공개 글 필요).
- Docker CLI가 제공되지 않아 Docker Compose 검증은 하지 못했습니다. H2만으로 대체하지 않고 로컬 실제 PostgreSQL을 검증했습니다.
- 이번 작업에서 실행한 검증 서버는 종료했습니다. 기존 개발 서버, main, 원격 저장소, 실제 배포는 변경하지 않았습니다.

추가 작업은 위 3개로 종료합니다. 향후 검토 후보는 수정 이력 및 비교 화면, 실제 검색 성능 측정 후 인덱스 개선, RSS 구독입니다. 이 후보들은 이번 작업에서 구현하지 않습니다.
