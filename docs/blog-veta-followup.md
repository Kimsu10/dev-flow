# 추가 개선 작업 (최대 3개)

기존 검색·읽기·404 개선 이후 추가 작업은 아래 세 가지로 제한합니다.

1. 작성 내용 유실 방지
2. 동시 수정 충돌 감지
3. 같은 카테고리의 다른 글 안내

## 1. 작성 내용 유실 방지

- 입력 직후 다른 페이지로 이동하거나 탭이 숨겨지면 800ms 지연을 기다리지 않고 임시저장을 시도합니다.
- 서버 저장 이후 변경 사항이 있으면 탭 종료 시 브라우저의 기본 경고를 요청합니다. 브라우저 정책상 경고가 항상 표시되는 것은 아닙니다.
- 에디터를 다른 게시글로 이동하면 인스턴스를 새로 만들고, 이전 글의 임시저장은 이전 키에 보관합니다.
- 서버 저장 성공 후 브라우저 저장소 삭제가 실패해도 서버 저장 실패로 표시하지 않습니다.
- 복원할 임시저장의 필드 타입을 검증합니다. 저장소가 차단되거나 용량이 부족하면 서버 저장을 안내합니다.
- 로컬 임시저장은 기존과 같이 같은 브라우저에만 남으며 복원은 명시적인 버튼으로 수행합니다.
