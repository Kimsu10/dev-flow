# 체험용 사용자 글쓰기

`USER` 계정은 로그인 후 메인의 AI 입력창에서만 새 글을 만들 수 있다. 카테고리는 마이그레이션 V8이 생성한 `체험용`으로 고정된다. 수동 생성, 관리자 초안 생성, 카테고리 추가, 발행 상태 변경, S3 첨부 API는 관리자 전용으로 유지한다.

## 모델과 비용 제한

```dotenv
OPENAI_MODEL=gpt-6.2-sol
TEST_USER_OPENAI_MODEL=gpt-6-luna
TEST_USER_MAX_OUTPUT_TOKENS=2000
TEST_USER_DAILY_AI_REQUESTS=50
```

관리자는 기존 `OPENAI_MODEL`을 사용한다. 사용자는 `TEST_USER_OPENAI_MODEL`을 사용하며 서버가 선택한다. 브라우저에서 모델·토큰·작성자·본문·카테고리를 보내도 생성 API는 질문과 공개 동의만 받는다. UI에 표시하는 모델도 `/api/user/ai-policy`의 실제 서버 설정에서 가져온다. 현재 기본값은 [웹 검색을 지원하는 GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)다. 가격과 사용 가능한 모델은 바뀔 수 있으므로 운영자가 설정을 검토해야 하며, 실시간 최저가를 자동 비교하거나 더 비싼 모델로 자동 전환하지 않는다.

체험 질문은 최대 1,000자, 출력은 기본 2,000토큰(설정 범위 256~3,000), 웹 도구 호출은 최대 1회이며 검색 컨텍스트를 `low`로 제한한다. 출력 토큰에는 추론 사용량이 포함되므로 실제 본문 길이는 달라진다. 웹 검색에는 별도 비용이 발생할 수 있다. [공식 가격표](https://developers.openai.com/api/docs/pricing)

계정당 하루 기본 50회(설정 범위 1~50), 한국 시간 자정에 날짜가 바뀐다. 성공적으로 발행하여 DB 저장까지 완료한 글만 횟수에 포함한다. AI 호출·초안 저장·글 저장 실패, 입력 검증 오류, AI 동시 실행 제한에 걸린 요청은 횟수를 차감하지 않는다. 수정·삭제도 횟수를 추가 차감하거나 환급하지 않는다. 출처 없는 완성된 창작 글은 발행할 수 있다.

AI 호출 전에 오늘의 사용량을 확인하고, 한도에 도달했으면 호출하지 않는다. AI 작성 후 여는 글 저장 트랜잭션 안에서 PostgreSQL의 원자적 UPSERT로 한도를 다시 확인하고 횟수를 증가시킨다. 글 저장이 실패하면 횟수 증가도 함께 롤백되며, 여러 서버/동시 요청이 한도를 넘겨 발행하지 못한다. 마지막 남은 횟수에 동시 요청이 몰리면 AI 생성이 끝났더라도 최종 한도 검사에서 429로 거절될 수 있으며, 거절된 요청은 카운트되지 않는다. 외부 AI 호출 중에는 DB 트랜잭션을 유지하지 않고 전체 AI 동시 실행 제한 2개를 유지한다. 앱의 횟수에서 제외된 실패 요청도 외부 서비스에서 이미 수행한 작업에는 비용이 발생할 수 있다.

이전 버전에서 이미 기록한 실패 횟수는 성공 횟수와 구분할 정보가 없어 자동 보정하지 않는다. 새 계산 방식은 변경 적용 후 요청부터 적용된다.

`.env`는 IntelliJ의 프로세스 환경변수와 다르다. 기본값을 바꾸려면 실행 구성에도 전달하거나 `scripts/start-backend.ps1`로 실행한다. 비밀값은 클라이언트에 전달하지 않는다.

## 조사 응답 검증

요청한 주제·장르·분량에 맞춰 작성하며 `tool_choice: "auto"`로 필요한 경우에만 웹을 검색한다. 창작 이야기나 자체 생성 설명에는 검색·출처를 강제하지 않는다. 외부 자료를 사용할 때는 출처를 인용하고 원문 전체를 복사하지 않도록 지시한다. Responses API에 `include: ["web_search_call.action.sources"]`를 요청한다. `url_citation` 메타데이터와, 본문 Markdown 링크 URL이 완료된 검색의 `action.sources` URL과 정확히 일치하는 출처를 함께 보존한다. 본문에서 인용하지 않은 검색 결과 전체나 생성된 임의 링크를 출처로 등록하지 않는다. [공식 웹 검색 문서](https://developers.openai.com/api/docs/guides/tools-web-search)

출처가 없으면 `sources: []`로 저장하고 `CITATIONS_NOT_VERIFIED`로 거절하지 않는다. 발행·미리보기·수정·로컬 임시저장 복원에서도 빈 목록을 허용한다. AI 작성 안내와 원래 질문은 항상 유지하며, 출처 영역은 실제 출처가 있을 때만 표시한다. 이 검증은 글에 담긴 주장의 사실 여부나 인용의 완전성을 보증하지 않으므로 작성자가 검토해야 한다. 출력 토큰 한도 때문에 응답이 중단되면 별도 `AI_OUTPUT_LIMIT`로 응답한다. 진단 로그에는 질문·초안·API 키·제공자 응답 원문을 기록하지 않는다.

현재 호출에는 웹 검색 도구만 연결되어 있고 이미지 생성 도구는 없다. 이미지가 첨부되거나 생성되었다고 가장하지 않도록 지시한다. 이미지 생성 API/SDK 및 생성 파일의 S3 저장 연결은 별도 기능이다.

## 본인 글 관리

사용자는 내 글에서 자신이 작성한 체험용 AI 글만 조회·수정·삭제한다. 수정 화면은 기존 Markdown 편집기를 재사용하지만 카테고리는 고정하고 공개/비공개/예약 제어를 제공하지 않는다. 수정은 제목·본문·요약과 버전만 받는다. 원래 질문·출처·작성자·카테고리·게시 일시·공개 상태는 서버가 기존 값으로 보존한다. 다른 사용자의 글은 404, 버전 충돌은 409로 응답한다. 삭제는 기존처럼 소프트 삭제다. 관리자에게는 기존 글쓰기·검토·상태 변경 권한이 유지된다.

## 검증 범위

모델 선택·최대 토큰·웹 도구 제한은 제공자 HTTP 테스트 대역으로 검증한다. 실제 PostgreSQL에서는 소유권, 위조 요청, 관리자 API 차단, 수정 충돌, 동시 일일 한도를 검증한다. 외부 유료 AI 호출 성공 여부는 이 자동 테스트로 보장하지 않는다.
